# PR-LAB-005 — Ingeniería social: principios

**Dominio:** D05 · **Enfoque:** Factor humano

| Campo | Descripción |
|---|---|
| Identificador | PR-LAB-005 |
| Nombre y versión | Ingeniería social: principios · v1.0 · nov-2026 · primera versión |
| Objetivo | Comprender técnicas de ingeniería social y las defensas que las reducen. |
| Dominio y fase | D05 · Fase 04 Análisis |
| Roles | Analista (Blue/Purple) y docente (revisor). |
| Entorno y autorización | Kali Linux en VM propia (VirtualBox/VMware), red host-only aislada de Internet; autorización: actividad académica dirigida por el docente, objetivo propio. |
| Entradas | Ejemplos de correos y URL sospechosos; heurística de Lab2_phishing.py; análisis de SayCheese y TBomb (PR-LAB-021). |
| Procedimiento | 1) Identificar principios (autoridad, urgencia, confianza). 2) Evaluar una URL con la heurística de phishing. 3) Analizar riesgos y vulnerabilidades de herramientas de ingeniería social. 4) Proponer medidas de concienciación. |
| Evidencias | Veredicto de la heurística (PR-LAB-020, prueba P04) y esquema de análisis (Anexo C). |
| Criterio de aceptación | Se justifica el veredicto con indicios concretos (subdominios excesivos, palabras de ingeniería social, ausencia de HTTPS). |
| Análisis defensivo | Capacitación periódica, verificación de remitentes y URL, HTTPS obligatorio y control de permisos del navegador. |
| Resultado | Cubierto por PR-LAB-015, 020 y 021. |
