# PR-LAB-021 — Análisis de herramientas SayCheese y TBomb (phishing y spam SMS)

**Dominio:** D05 · **Enfoque:** Factor humano

| Campo | Descripción |
|---|---|
| Identificador | PR-LAB-021 |
| Nombre y versión | Análisis de SayCheese y TBomb · v1.0 · nov-2026 · primera versión |
| Objetivo | Analizar defensivamente dos herramientas de ingeniería social y saturación: riesgos y vulnerabilidades que explotan. |
| Dominio y fase | D05 · Fase 04 Análisis (concienciación) |
| Roles | Analistas (Blue/Purple), docente (revisor). |
| Entorno y autorización | Análisis documental; sin ejecución contra terceros. |
| Entradas | Esquema de análisis (imagen del Anexo C). |
| Procedimiento | Descripción de qué hace cada herramienta, riesgos de uso y vulnerabilidades explotadas (permisos de cámara del navegador; APIs de SMS/OTP sin límites de tasa). No se ejecutan contra personas reales. |
| Evidencias | Mapa mental del Anexo C. |
| Criterio de aceptación | Se identifican riesgos comunes: falta de autorización, falsa sensación de anonimato y vulnerabilidad del usuario. |
| Análisis defensivo | Concienciación del usuario, límites de tasa en APIs y control de permisos del navegador. |
| Resultado | Elaborado. El uso contra terceros sin autorización puede constituir delito informático. |
