# PR-LAB-001 — Comandos Shell y Kali Linux

**Dominio:** D01 · **Enfoque:** Transversal

| Campo | Descripción |
|---|---|
| Identificador | PR-LAB-001 |
| Nombre y versión | Comandos Shell y Kali Linux · v1.0 · nov-2026 · primera versión |
| Objetivo | Preparar el entorno de trabajo y dominar los comandos base para ejecutar y documentar las demás pruebas. |
| Dominio y fase | D01 · Fase 01 Preparación |
| Roles | Ejecutor: estudiante. Revisor: docente. |
| Entorno y autorización | Kali Linux en VM propia (VirtualBox/VMware), red host-only aislada de Internet; autorización: actividad académica dirigida por el docente, objetivo propio. |
| Entradas | VM Kali Linux; tabla de comandos del Taller de comandos Kali (sudo, apt, systemctl, ss, ip, export/echo, awk, printf, head). |
| Procedimiento | 1) Actualizar el sistema con apt. 2) Crear la estructura de directorios del laboratorio. 3) Consultar servicios y puertos con systemctl y ss. 4) Revisar direccionamiento con ip -br a. 5) Filtrar salidas con awk, head y printf. 6) Registrar cada comando en la bitácora. |
| Evidencias | Bitácora de comandos y capturas de terminal; ver PR-LAB-018. |
| Criterio de aceptación | Cada comando se ejecuta con su salida y su finalidad explicadas. |
| Análisis defensivo | Principio de mínimo privilegio: usar sudo solo cuando la tarea lo requiere. |
| Resultado | Cubierto por el Taller de comandos Kali (PR-LAB-018). |
